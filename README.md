# Homework4TimersOnAndroid
This is a timer app for Android. It is generated from Homework4Timers iOS27 app by Google Gemini 3.6 Flash. You can set up a working and relaxation time intervals like a school bell.
You can repeat intervals any time like a professional scheduler.

User interface is multilingual (english and hungarian), please see the settings panel.
